# 📸 Slider Images Folder

Place your photos here for the 3D Photo Gallery slider.

## Naming Convention
- Name your images with numbers for ordering: `1.jpg`, `2.jpg`, `3.jpg`, etc.
- Or use descriptive names: `campus.jpg`, `hackathon.jpg`, `team.jpg`

## Supported Formats
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

## How to Add
1. Drop your images in this folder
2. Open `src/components/PhotoGallery3D.jsx`
3. Update the `galleryImages` array with your image paths and captions

## Recommended
- Image dimensions: 800x600px or similar 4:3 ratio
- File size: Keep under 500KB for fast loading
- Use `.webp` format for best performance
