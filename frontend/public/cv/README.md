# 📄 CV / Resume Folder

Place your CV/Resume PDF file here.

## How to Use
1. Drop your CV file as `resume.pdf` in this folder
2. The website will automatically show it in the Resume section
3. Visitors can view, download, and print your CV

## File Name
- Default expected: `resume.pdf`
- If you use a different name, update the path in `src/components/ResumeSection.jsx`
